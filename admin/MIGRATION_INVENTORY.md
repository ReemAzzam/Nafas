# جرد الترحيل

## الواجهات

تم تحويل الشاشات الـ25 في HTML إلى مسارات تطبيق فعلية: الرئيسية، المستخدمون، تفاصيل المستخدم، المقالات، محرر المقال، التمارين، محرر التمرين، مراجعة التعليقات، التقييمات، المختصون، خطوط الدعم، كتالوج مساحات نَفَس، إنشاء المقطع، تحريره، المحذوفات، ربط الصوت بالتمرين، محررا المختص والخط الساخن، تفاصيل البلاغ، تفاصيل التقييم، الدخول، الاستعادة، التحقق، أمان الحساب، وحالات النظام.

## المكونات المشتركة

- `AdminLayout`: الشريط الجانبي، الترويسة، التنقل، بيانات الأدمن، والخروج.
- `AsyncState`: التحميل، الخطأ، إعادة المحاولة، والفراغ.
- `Pagination`: ترقيم Laravel الحقيقي.
- `ConfirmDialog`: تأكيد الأفعال الحساسة.
- بطاقات المؤشرات والجداول والنماذج وحالات النشر المشتركة.

## التفاعلات المنفذة

- البحث والفلترة والترقيم عبر query parameters.
- النشر وإلغاء النشر والحذف والاستعادة حيث يدعمها Laravel.
- الحظر وفك الحظر.
- نماذج multipart للصور وM4A دون تعيين `Content-Type` يدوياً.
- إنشاء/تعديل المقال والتمرين والصوت والمختص وخط الدعم.
- إضافة وحذف خطوات التمرين وربط مقطع صوتي منشور.
- مراجعة البلاغات وإخفاء/استعادة التعليقات ومراجعة التقييمات.
- حفظ الجلسة في `sessionStorage` وإرفاق Bearer token ومسحها على 401.
- RTL، التنقل بلوحة المفاتيح، focus states، وتخطيطات سطح المكتب/اللوحي/الهاتف.

## قرارات مقصودة

- لا تُعرض اليوميات أو جهات SOS الخاصة في الإدارة لأنها غير مكشوفة في Laravel وهذا يتفق مع خطة العمل.
- لا توجد بيانات Mock داخل مكونات الإنتاج.
- معاينة الصوت المحمي تتم عبر مسار معاينة الأدمن بتحميل Blob مصرح، لا عبر تمرير `audio_url` مباشرة إلى `<audio>`. صلاحية المسودات تعتمد على إعدادات Laravel.
