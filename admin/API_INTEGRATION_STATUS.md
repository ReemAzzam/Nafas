# مصفوفة تكامل Laravel API

المصدر: `routes/api.php` وControllers وFormRequests وResources في مشروع Laravel المرفق، مع مطابقة مجموعة Postman. المصادقة الفعلية هي Laravel Sanctum Personal Access Tokens عبر `Authorization: Bearer`، وليست جلسة Sanctum SPA.

> `Not Yet Tested` تعني أن العقد موصول في الكود ولم يُختبر على خادم Laravel حي؛ لم تُقدّم بيانات دخول أو عنوان خادم عامل.

لم تستخدم الواجهة Mock API ولم تُنشئ أي backend JavaScript. البيانات لا تظهر إلا من Laravel، والحالات المحجوبة تبقى معروضة كقيود صريحة.

معاينة الصوت الحالية تتجاوز تشغيل `audio_url` مباشرةً: تستخدم واجهة الأدمن `/admin/audio-tracks/{audioTrack}/preview` عبر عميل API ثم Blob URL. يلزم التحقق من وجود هذا المسار وصلاحيات المسودات على نسخة Laravel الحية؛ لا يتضمن مجلد العمل الحالي مصدر Laravel.

تحقق محلياً من المسار نفسه دون تمرير token: GET أعاد 401 (ليس 404)، وCORS preflight من `http://localhost:5173` أعاد 204 مع السماح بـ`Authorization` وGET. هذا يثبت وجود مسار محمي وإعداد preflight محلي؛ لا يثبت تشغيل الملف أو صلاحية معاينة المسودة، إذ لم تتوفر جلسة أدمن للتحقق من الاستجابة المصرح بها. سطر التشغيل بعنصر HTML أعلاه تاريخي ويستبدله مسار المعاينة الحالي.
